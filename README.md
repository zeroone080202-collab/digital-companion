# MEDI | 의료 지식 챗봇
## Research beta 0.1.0 / 2026-09-21

이 프로젝트는 **이미지 첨부 + 업로드 자료 검색 + 대화형 AI**를 연결한 독립 웹 챗봇입니다. 게임 패치가 아니며, 새 프로젝트로 실행합니다.

**임상 검증된 진단 제품이 아닙니다.** 실제 환자의 식별 정보를 입력하지 마세요. 의사의 진단·처방·응급 판단을 대체하지 않습니다.

### 처음 실행하기

Windows에 Python 3.11~3.13을 설치한 뒤 압축을 풀고 `start_local.bat`를 실행하세요. macOS/Linux는 `bash start_local.sh`를 사용합니다. 첫 실행에는 패키지 설치와 약 842 MiB의 지식 DB 복원이 진행됩니다. 여유 디스크 3GB 이상을 확보하세요.

접속: `http://127.0.0.1:8000`

API 키가 없으면 **자료 검색 체험 모드**입니다. 새로운 AI 답변을 생성하거나 이미지를 분석한 것처럼 표시하지 않습니다.

AI를 연결하려면 자동 생성된 `.env`에 본인의 `OPENAI_API_KEY`를 설정하고 서버를 재시작하세요. 키를 채팅창에 보내거나 GitHub에 올리지 마세요. ChatGPT 구독과 API 결제는 별개입니다.[1]

### 들어 있는 기능

| 구분 | 구현 범위 |
|---|---|
| 대화 | 의학 지식·건강 정보·학습 질문, 최근 대화 문맥 연결 |
| 근거 | 67,485개 고유 문서, 200,492개 검색 단위. 문서명·출처 메타데이터·발췌문 표시 |
| 이미지 | JPG/PNG/WebP, 한 번에 2장, 각 5MiB까지. 검사결과지·외부 사진의 비진단적 설명 경로 |
| 계정 | Supabase 이메일 가입·로그인, 초대 코드, 개인별 대화 조회·삭제 |
| 저장 | 선택한 대화만 암호화 저장. 이미지 파일 자체는 저장하지 않음 |
| 개선 | 이용자가 따로 동의한 피드백 수집, 운영자·의료 검토자의 검토 후 지식 추가 |
| 운영 | Render 설정, 사용자별/전체 일일 API 호출 한도, 개인 정보 안내 |

프롬프트와 기본 규칙으로 의료 범위를 제한하지만, 우회·오류가 전혀 없다고 보장하지 않습니다. 응급 키워드 규칙도 검증된 환자 분류 체계가 아닙니다.

### 중요한 구분

이 버전은 **기존 대화 모델 + 데이터 검색(RAG)**입니다. GPT와 같은 대규모 모델을 새로 학습한 것이 아닙니다. 기본 모델은 `gpt-5.4-mini`이며, 접근 가능한 호환 모델으로 `.env`에서 변경할 수 있습니다.[2]

골절 이미지 1,539장은 구조·라벨·중복 위험을 점검했습니다. **영상 모델을 학습하지 않았고, X-ray/CT/MRI 자동 판독은 비활성화된 상태**입니다. 결과지 사진의 숫자·단위도 사용자 확인이 필요합니다.[3]
