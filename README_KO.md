# MEDI v0.10.3 증상 핵심 강조 패치

## 무엇이 바뀌나요?
사용자가 자신의 증상, 검사결과, 부상, 약 또는 의료 이미지를 제시했을 때 Gemini가 현재 질문을 다시 해석해 답변 안에 `내 증상과 특히 관련된 부분`을 동적으로 만듭니다.

이 영역은 고정답변이 아닙니다. 매 질문마다 사용자가 실제로 말한 증상과 실제 이미지 관찰 결과를 기준으로 2~4개의 핵심만 골라 새로 작성합니다.

일반 의학 개념 질문에는 이 상자를 억지로 만들지 않습니다.

## 교체 파일
- app/provider.py
- static/app.js
- static/app.css

GitHub의 같은 경로에 각각 전체 덮어쓰기 후 Commit하세요.
그 다음 Render에서 `Manual Deploy -> Clear build cache & deploy`를 실행하세요.

## 표시 예시
사용자: `기침이 4일째고 열이 나는데 X-ray에서 하얗게 보이는 부분이 있다고 했어`

MEDI 답변 중:

### 내 증상과 특히 관련된 부분
• 기침 + 발열 → 감염성 호흡기 질환을 확인할 때 함께 보는 증상 조합입니다.
• X-ray의 음영 변화 → 증상과 함께 있을 때 폐렴 등 여러 원인을 의료진이 구분해 확인하는 단서가 될 수 있습니다.
• 숨참이 새로 생기거나 심해짐 → 진료 시기를 앞당겨야 하는지 판단할 때 중요한 정보입니다.

확정 진단처럼 표현하지 않고, 왜 그 항목이 현재 상황에서 중요한지를 설명합니다.
